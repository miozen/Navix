# P0 最小回归清单

> 在每次 P0 代码变更后执行。结果记录格式：通过 / 失败 / 阻塞 + 备注。

## 页面与静态资源

- [ ] `/` 打开页面，标题、搜索框、分区卡片、页脚正常显示。
- [ ] `ads.txt` 可通过根路径访问。
- [ ] Tailwind / Font Awesome 等 CDN 资源加载正常。
- [ ] `src/`、`docs/`、`wrangler.jsonc` 等内部文件无法通过 HTTP 访问。

## 导航与外观

- [ ] 语言切换后界面文案变化，刷新后保持。
- [ ] 主题切换（明/暗）正常，刷新后保持。
- [ ] 自定义壁纸设置与清除正常。
- [ ] 动态分区：新增、重命名、删除、拖拽排序正常。
- [ ] 分区内链接：新增、删除、跳转正常。
- [ ] 友情链接：新增、删除、跳转正常。
- [ ] 天气与定位失败时显示默认文案，不影响主功能。

## 后台与云端配置

- [ ] 双击页脚可触发后台入口。
- [ ] 使用新密码登录成功；错误密码失败。
- [ ] 修改壁纸 / 分区 / 友链后云端保存成功。
- [ ] 修改密码后旧会话失效，需重新登录。
- [ ] 退出登录后写操作返回 401，前端提示重新登录。
- [ ] 网络异常或超时时不丢失正在编辑的内容（完整验证在 P1）。

## 安全回归

- [ ] 匿名 `GET /api/config` 不包含任何管理员凭据。
- [ ] 旧密码与旧 Token 均无法登录或写入。
- [ ] 直接 POST 携带 `adminPwd` 字段返回 400。
- [ ] 跨源 POST 写操作返回 403。
- [ ] 恶意标题 / 链接名不会执行脚本。
- [ ] `/api/links` 不再提供可用写入口。
