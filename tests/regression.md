# P0 最小回归清单

> 在每次 P0 代码变更后执行。结果记录格式：通过 / 失败 / 阻塞 + 备注。

## 页面与静态资源

- [ ] `/` 打开页面，标题、搜索框、分区卡片、页脚正常显示。
- [ ] `ads.txt` 与 `favicon.ico` 可通过根路径正常访问，无 404 报错。
- [ ] `/assets/css/app.css` 与 `/assets/js/main.js` 可加载，页面无内联 `<style>` / `<script>`。
- [ ] 所有带 `onclick` / `ondrag*` 的控件仍可正常触发（模块入口已将处理器挂到 window）。
- [ ] Tailwind / Font Awesome 等 CDN 资源加载正常。
- [ ] `src/`、`docs/`、`wrangler.jsonc` 等内部文件无法通过 HTTP 访问。
- [ ] 桌面端左上角设置面板宽度约 340px，搜索引擎长 URL 模板编辑清晰，移动端不溢出。

## 导航与外观

- [ ] 语言切换后界面文案变化，刷新后保持。
- [ ] 主题切换（明/暗）正常，刷新后保持。
- [ ] 自定义壁纸设置与清除正常。
- [ ] 动态分区：新增、重命名、删除、拖拽排序正常。
- [ ] 分区内链接：新增、删除、跳转正常；优先加载 DuckDuckGo 图标，未收录或内网站点回退站点自身 `/favicon.ico`，均不可用时回退首字母/汉字圆标。
- [ ] 友情链接：新增、删除、跳转正常，采用同款三级图标加载与首字符兜底。
- [ ] 页面向下滚动超过 160px 时显示回到顶部按钮，点击平滑滚回顶部；左上角设置按钮始终固定在视口左上角且可正常展开面板。
- [ ] 天气与定位失败时显示默认文案，不影响主功能。

## 后台与云端配置

- [ ] 单击页脚可触发后台入口（未登录时弹出遮罩密码框登录 / 已登录确认后退出）。
- [ ] 修改密码时确认旧密码也使用遮罩密码框，不以明文显示。
- [ ] 会话失效后刷新页面，首屏 `GET /api/session` 自动探活并退出“伪登录”态。
- [ ] 使用新密码登录成功；错误密码失败。
- [ ] 修改壁纸 / 分区 / 友链后云端保存成功。
- [ ] 保存过程中显示“正在保存…”，重复点击不会重复提交。
- [ ] 保存成功后显示“已保存”。
- [ ] 版本冲突时返回 409，并提示刷新确认，不静默覆盖云端配置。
- [ ] 网络超时显示“结果未知”，本地编辑内容不丢失。
- [ ] 修改密码后旧会话失效，需重新登录。
- [ ] 退出登录后写操作返回 401，前端提示重新登录。
- [ ] 网络异常或超时时不丢失正在编辑的内容（完整验证在 P1）。
